# Technical Writing

This repository contains notes, practical work, examples, and documentation prepared as part of the **Technical Writing** course. It covers tools and technologies used for technical documentation, document preparation, version control, and presentations.

## Repository Contents

### 1. LaTeX
Covers the fundamentals and advanced features of LaTeX for creating structured and professionally formatted documents.

**Topics include:**
- Introduction to LaTeX and document structure
- Text formatting and environments
- Mathematical equations and tables
- Figures, colours, and customization

### 2. Beamer
Covers the use of LaTeX Beamer for creating professional presentations.

**Topics include:**
- Creating presentation slides
- Frames and slide structure
- Themes and formatting
- Mathematical expressions and visual elements

### 3. Documentation Tools
Covers tools used for creating, formatting, and maintaining technical documentation.

**Topics include:**
- **Doxygen:** Generating documentation from source code using structured comments.
- **Google Docs:** Creating, formatting, sharing, and collaborating on documents.

### 4. Git and GitHub
Covers version control and collaborative software development using Git and GitHub.

**Topics include:**
- Introduction to version control
- Git commands and basic workflow
- Repository creation and management
- Branching and merging
- Uploading projects to GitHub
- Collaboration using pull requests

## Purpose of This Repository

The purpose of this repository is to maintain course-related work in an organized manner, demonstrate practical knowledge of technical writing tools, and keep examples and documentation accessible for future reference.
