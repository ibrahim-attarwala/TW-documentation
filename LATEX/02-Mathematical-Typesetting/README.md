# Phase 2: Mathematical Typesetting

This module covers scientific equations, symbols, multi-line alignments, and matrix structures in LaTeX.

## Files

- `Display.tex` – Inline and display equations, mathematical fonts, symbols, fractions, roots, sums, products, and integrals.
- `Arrays-and-Matrix.tex` – Multi-line equations, arrays, piecewise functions, and delimited matrix environments.

## Concepts Covered

* **Inline & Display Equations**
  * Write inline math using standard delimiters.
  * Write display equations centered on their own lines using dedicated equation environments.
  * Add automatic numbering or suppress it using dedicated starred environments.

* **Mathematical Fonts & Symbols**
  * Apply specific math typefaces including calligraphic, Fraktur, and blackboard bold.
  * Include Greek letters, binary operators, and relation/logic symbols.

* **Core Math Structures & Calculus**
  * Typeset superscripts and subscripts.
  * Construct fractions, roots, summations, products, and integrals.

* **Multi-line Equations, Arrays & Matrices**
  * Handle multi-line equations using alignment and grouping environments.
  * Build arrays and case-based piecewise functions using array environments paired with automatic sizing delimiters.
  * Construct matrices with various delimiters such as parentheses, square brackets, and determinants, alongside compact inline variants.

## Compilation

Both files can be compiled using offline environments or online platforms.
