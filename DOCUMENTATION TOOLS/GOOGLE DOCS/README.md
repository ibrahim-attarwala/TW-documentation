# Google Docs

This section covers the use of **Google Docs** for creating, formatting, sharing, and collaborating on documents.

## Topics Covered

- Creating and formatting documents
- Using headings, tables, images, and links
- Comments and suggestions
- Sharing documents and managing access
- Version history and restoring earlier versions
- Citations and bibliography
- Importing and exporting document formats

## Key Features

| Feature | Purpose |
|---|---|
| Real-time collaboration | Allows multiple users to work on a document together |
| Formatting tools | Provides headings, tables, images, drawings, links, and equations |
| Comments and suggestions | Helps reviewers give feedback |
| Version history | Tracks edits and allows earlier versions to be restored |
| Import and export | Supports formats such as DOCX, PDF, ODT, RTF, HTML, and TXT |

## Useful Tools

- **Headings and Table of Contents:** Organize long documents.
- **Comments and Suggestions:** Review content without directly changing the original text.
- **Version History:** Track changes and restore previous versions.
- **Citations:** Add sources in MLA, APA, or Chicago style and generate a bibliography.

## Best Practices

- Use consistent headings and formatting.
- Organize content with headings and a table of contents.
- Assign suitable editing or reviewing access.
- Resolve comments and suggestions when they are no longer needed.
- Export or back up important versions of documents.
