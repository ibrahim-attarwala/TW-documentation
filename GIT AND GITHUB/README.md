This section covers the fundamentals of **Git and GitHub**, including version control, repository management, essential Git commands, and collaboration on software projects.

## Git vs GitHub

| Git | GitHub |
|---|---|
| Version control system | Hosting and collaboration platform |
| Works locally | Provides remote repositories |
| Tracks changes in files | Helps share and review projects |
| Supports commits, branches, and merges | Supports pull requests, issues, and code reviews |

## Essential Git Commands

| Command | Purpose |
|---|---|
| `git init` | Initializes a new repository |
| `git clone` | Copies a remote repository |
| `git status` | Displays the current repository status |
| `git add` | Adds changes to the staging area |
| `git commit` | Saves staged changes |
| `git log` | Displays commit history |
| `git diff` | Shows differences between changes |
| `git restore` | Discards unstaged changes |
| `git push` | Uploads commits to a remote repository |
| `git pull` | Fetches and integrates remote changes |
| `git branch` | Lists or manages branches |
| `git merge` | Combines branches |

## Basic Git Workflow

Git uses three main areas:

1. **Working Directory:** Where files are created or modified.
2. **Staging Area:** Where changes are selected for the next commit.
3. **Repository:** Where committed project history is stored.

The basic workflow is:

`Edit → Stage → Commit → Push`

## GitHub Collaboration

GitHub provides features that make teamwork easier:

- **Repositories:** Store and manage project files.
- **Branches:** Allow developers to work on separate features.
- **Pull Requests:** Propose changes and request code reviews.
- **Issues:** Track bugs, tasks, and improvements.
- **Merging:** Integrate approved changes into the main branch.

## Best Practices

- Commit changes frequently and logically.
- Write clear and meaningful commit messages.
- Use descriptive branch names.
- Review changes before committing.
- Pull or fetch updates regularly.
- Test changes before merging.
- Never upload passwords or sensitive credentials.
- Maintain proper project documentation.

## Conclusion

Git helps developers track changes and manage project history, while GitHub makes it easier to host projects and collaborate with others. Together, they form an important part of modern software development.
